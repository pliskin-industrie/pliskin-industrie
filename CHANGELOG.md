# Changelog

## 0.8.2
- Fitting für alle Schiffe: 210 Schiffe statt 3, mit eigenen Bildern aus den Spieldaten (vorne, oben, Seite) / Ship fitting for all ships: 210 ships instead of 3, with own renders from the game files.
- Fitting: noch fehlende Bilder zeigen den Platzhalter „Bild folgt“ statt kaputter Bilder / Missing images show a “Bild folgt” (image coming) placeholder instead of broken images.
- Fitting: neues Layout mit drei Ansichten, Schiffsauswahl als Hangar mit Filtern (Hersteller, Rolle), Teile-Vergleich, bis zu 4 Entwürfe, Ausstattung teilen und laden / New layout with three views, hangar ship picker with filters, part comparison, up to 4 drafts, share and load loadouts.
- Lager und Tour: Kisten im Cargo-Grid werden in der richtigen Reihenfolge und liegend gezeichnet, Bilder und Material-Symbole laden zuverlässig, zu viele Kisten öffnen weitere Freight Elevators / Crates draw in the right order and lying flat, images and symbols load reliably, overflow crates open more freight elevators.
- Englisch für Erfassung, Craft-Fenster und Lager-Ansicht; Hilfe zur Erfassung ergänzt / English for capture, craft window and storage view; more help on capture.
- Desktop-Ansicht auf dem Handy wählbar („Desktop-Seite“ im Browser oder Knopf), Handy-Ansicht per Knopf zurück / Desktop view selectable on phones.

## 0.8.1
- StarStrings: Blueprint-Markierungen passen jetzt zum aktuellen StarStrings von MrKraken (erkennt die installierte Fassung selbst) / StarStrings marks work with the current MrKraken release (detects the installed version).
- Fitting: WC III zeigt Einsitzer direkt von vorne, alle anderen Designs schräg; Dreh-Ansicht dreht halb so schnell; Polaris-Drehansicht für alle Paints / WC III front view for single-seaters, slower turntable, Polaris turntable for all paints.

## 0.8.0
Erste öffentliche Vorab-Version / first public early-access version.
- Schiffs-Fitting (im Aufbau): Gladius, Golem, Polaris – Waffen, Racks/Raketen, Türme, Komponenten, Mining-Köpfe/Module/Gadgets, Paints, Flight Blades, Pips; Ausstattung → Crafting-Plan / Ship fitting (work in progress), loadout → crafting plan.
- StarStrings (MrKraken): Blueprint-Häkchen in Missionsbeschreibungen, [Gesucht] grün / StarStrings blueprint marks, [Gesucht] in green.
- Log-Sync erkennt Bauteil-Namen im StarStrings-Format („7CA 'Nargun' [Civilian S03 A]“) / Log sync understands StarStrings component names.
- Gecraftete Generatoren: Qualität ändert die Pips im Fitting / Crafted power plants: quality changes pips in the fitting.
- Menü „Schiffe“ heißt jetzt „Meine Schiffe“, Cargo-Grid-Einstellung im Fitting / “Ships” renamed to “My ships”.

### Vorher (intern 1.0.0) / earlier (internal 1.0.0)
- Fertiges Programm für Windows und Linux – kein Server, kein Browser nötig / Standalone program for Windows and Linux.
- Server-Modus (Einstellungen → Programm): Handy, Laptop und andere PCs im Heimnetz greifen zu / Server mode for your home network.
- Updates über GitHub: Hinweis bei neuer Version (abschaltbar), jede Version wählbar / Updates via GitHub, any version selectable.
- Deutsch und Englisch, wählbar beim ersten Start und in den Einstellungen / German and English.
- Ersteinrichtung: Sprache, Design (Standard: SC · Holo), leer starten oder Demo / First-start setup.
- Tour: Hin- und Rückfracht, kürzeste Route, Frachtraum, Tankstellen; Übersicht aller Touren / Round trips, shortest route, refuel points.
- Zwei Geräte gleichzeitig: Änderungen werden zusammengeführt / Changes from two devices are merged.
- Katalog: eigene Bilder aus den Spieldaten, Werkzeuge-Gruppe, Helmformen / Catalog with own renders.
