# Changelog

## 1.0.0
- Fertiges Programm für Windows und Linux – kein Server, kein Browser nötig / Standalone program for Windows and Linux.
- Server-Modus (Einstellungen → Programm): Handy, Laptop und andere PCs im Heimnetz greifen zu / Server mode for your home network.
- Updates über GitHub: Hinweis bei neuer Version (abschaltbar), jede Version wählbar / Updates via GitHub, any version selectable.
- Deutsch und Englisch, wählbar beim ersten Start und in den Einstellungen / German and English.
- Ersteinrichtung: Sprache, Design (Standard: SC · Holo), leer starten oder Demo / First-start setup.
- Tour: Hin- und Rückfracht, kürzeste Route, Frachtraum, Tankstellen; Übersicht aller Touren / Round trips, shortest route, refuel points.
- Zwei Geräte gleichzeitig: Änderungen werden zusammengeführt / Changes from two devices are merged.
- Katalog: eigene Bilder aus den Spieldaten, Werkzeuge-Gruppe, Helmformen / Catalog with own renders.
